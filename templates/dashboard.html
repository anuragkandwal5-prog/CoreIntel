Security toolkit

Four small tools to help you spot scams, catch risky code, look up safe commands, and check your own exposure — everything runs in your browser.

ai_assistant.sh

Ask anything, or paste something you want explained. This runs on Groq directly inside the page.

scam_scanner.sh

Paste a suspicious message, email, or link. This flags common scam patterns — a quick gut-check, not a guarantee.

code_scanner.sh

Paste a snippet of your own code. This checks for a handful of well-known risky patterns — it's a sanity check, not a full audit.

cheat_sheet.md

Quick reference for common tools. For network tools, only use these against systems you own or are explicitly authorized to test.

privacy_check.sh

Real breach lookups need a server holding an API key, so this won't fake a live result — it points you to what actually helps.

Everything above runs client-side. Nothing you type is sent anywhere.
